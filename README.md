# Культура девелопмента — сайт-платформа

Сайт бюро земельных возможностей. Ядро — **Калькулятор девелопера**: рабочая модель
допроектной оценки, которая считает потенциал участка, экономику проекта и риски
до старта. Палитра: белый, стекло, изумрудный акцент, чёрная пилюля навигации.

## Стек

| Слой        | Технология                                       |
| ----------- | ------------------------------------------------ |
| Фреймворк   | Next.js 16 (App Router, статическая генерация)    |
| Стили       | Tailwind CSS v4 (токены в `app/globals.css`)      |
| 3D          | three.js + React Three Fiber + drei              |
| Анимация    | motion (Framer Motion) + Lenis (плавный скролл)  |
| Типографика | Inter Tight (заголовки) · Inter (текст)          |

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # продакшн-сборка
npm run start   # запуск собранного сайта
```

## Структура

```
app/
  page.tsx        Главная: герой → жизненный цикл → калькулятор-ядро →
                  аудитории и Excel vs → «Один экран» → CTA
  kalkulyator/    Калькулятор девелопера во всю ширину + пять этапов
  komanda/        Компетенции по этапам (каркас, ждёт данных)
  kontakty/       Форма запроса демо и реквизиты
components/
  layout/         Шапка-пилюля, подвал, плавный скролл
  sections/       Экраны страниц
  calculator/     Дашборд, ноутбук, компактная тёмная сводка
  three/          Сцены: участок → застройка, объекты аудиторий, окружение
  ui/             Пилюли, кнопки, иконки, появления

```

## Как подставить данные

1. **Тексты** — `content/site.ts`. Вёрстка от копирайта не зависит. Места, где данных
   не было в брифе (команда, телефон, почта, Telegram), помечены `// TODO(бриф)`.
2. **Нормативы модели** — `lib/model.ts`: доля продаваемой площади, цены и себестоимость
   по классам, доли затрат (`SHARES`), плотности по зонам. Формулы менять не нужно.

## Как считает калькулятор

`площадь участка × плотность зоны` → GBA → `× доля продаваемой площади` → GSA и выручка.
Затраты: участок, СМР, сети, проектирование, управление, маркетинг, финансирование.
Денежный поток помесячный, **через эскроу**: деньги дольщиков раскрываются после ввода,
стройка идёт на проектном финансировании. Из потока считаются NPV (дисконтированием)
и IRR (методом бисекции). Сценарии сдвигают цену, себестоимость и темп продаж;
чувствительность показывает изменение IRR при отклонении фактора на ±10%.

## Что ещё не подключено

- **Приём заявок**: обработчик формы в `components/sections/ContactForm.tsx` — заглушка.
- **Экспорт сметы**: кнопка в дашборде пока не выгружает файл.
- **Ссылка на Telegram** и контактные данные — заглушки в `content/site.ts`.

## Доступность и производительность

- 3D грузится только на клиенте (`components/three/Lazy.tsx`), окружение сцен собрано
  из источников света внутри three — внешние HDRI не загружаются.
- `prefers-reduced-motion` отключает плавный скролл, появления и раскрытие ноутбука.
- Видимый фокус на всех интерактивных элементах, вёрстка адаптируется до 390 px.
