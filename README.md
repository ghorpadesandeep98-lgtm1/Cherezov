# Культура девелопмента — сайт

Реализация макета `design/Адаптив - проверка.html` (хендофф Claude Design)
на Next.js (App Router) + TypeScript.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
```

## Структура

```
src/
  app/
    layout.tsx          Manrope через next/font, подключение токенов
    page.tsx            порядок секций страницы
    api/lead/route.ts   приём заявок: письмо на почту + строка в Google Таблицу
    icon.svg            favicon
  components/
    ds/Logo.tsx         логотип «культура девелопмента» (+ logoPaths.ts — контуры SVG)
    v3/                 по компоненту на секцию макета + CSS-модуль
      Orb.tsx           фирменный объёмный шар, общий для нескольких секций
      OneScreen.tsx     секция #screen: интерфейс «Калькулятора» в рамке макбука
      calculator/       пять вкладок интерфейса + общий Dashboard.module.css
  data/v3/
    content.ts          тексты и списки секций
    calculator.ts       демо-модель проекта: сценарии, ТЭП, риски, выводы
  lib/                  валидация заявки, отправка письма, запись в таблицу
  styles/
    globals.css         база страницы
    tokens/             токены дизайн-системы (цвета, типографика, стекло, движение)
public/assets/v3/       рендеры и фото из бандла
design/                 исходный HTML макета
```

## Что стоит знать

**Токены дизайн-системы** скопированы из бандла без изменений, кроме одного:
`tokens/glass.css` ссылался на `assets/liquid-glass.svg`, которого в экспорте нет.
Переменные `--glass-refract*` в текущем макете не используются.

**Keyframes живут внутри CSS-модулей**, а не в `globals.css`: css-modules локализует
и определение `@keyframes`, и ссылку на него в `animation`. Если вынести определение
в глобальный файл, имена перестают совпадать и анимация молча не работает. Исключение —
`kdModelRise`: карточку контактов анимирует JS, подставляя имя инлайном мимо модулей.

**Сцена «Калькулятора»** рисуется в фиксированных пикселях (1169×840) и целиком
масштабируется под вырез в рамке макбука: `OneScreen` меряет вырез и подбирает ширину
сцены (1060–1500 px) и коэффициент так, чтобы не оставалось полей. Ниже 820 px рамка
прячется, сцена листается по горизонтали — рядом появляются подсказка и кнопка-стрелка.

**Форма заявки** отправляет имя и телефон на `/api/lead`. Почта в модели заявки
осталась необязательной: если её нет, письмо приходит без «Reply-To». Каналы доставки
настраиваются переменными окружения — см. `.env.example`; если не настроен ни один,
эндпоинт отвечает 503, и форма показывает ошибку с почтой для связи.

## Адаптив

Макет свёрстан от 1440 px; в исходнике раскладку переключал JS по `window.innerWidth`.
Здесь те же переключения сделаны медиазапросами, поэтому первый кадр приходит уже
в нужной раскладке.

- **720 px** — основная граница: пункты меню уезжают в бургер, прячется кнопка в пилюле
  и кнопки в герое, карточки аудиторий теряют шахматный сдвиг, таблица сравнения
  сжимается до двух колонок с критерием на всю строку, лента этапов становится
  свайп-каруселью, шаги процесса подсвечиваются по скроллу, а не по наведению.
- **820 px** — граница сцены «Калькулятора»: рамка макбука уходит, сцена скроллится.

Проверено на 390 и 1440 px: горизонтального скролла нет, ошибок в консоли нет.

**Движение.** Все анимации выключаются при `prefers-reduced-motion: reduce`;
параллакс и всплытие карточки в контактах при этом тоже не запускаются.
