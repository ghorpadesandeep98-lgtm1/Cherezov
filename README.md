# Культура ДИТОН — сайт-платформа

Многостраничный сайт полиграфического комбината: лёгкая светлая палитра, стекло,
салатовый акцент и 3D-объекты бренда. Центральный элемент — **Калькулятор ДИТОН**:
живой интерфейс расчёта тиража, встроенный в макет ноутбука на главной и открытый
на всю ширину на отдельной странице.

## Стек

| Слой        | Технология                                                     |
| ----------- | -------------------------------------------------------------- |
| Фреймворк   | Next.js 16 (App Router, статическая генерация)                  |
| Стили       | Tailwind CSS v4 (токены в `app/globals.css`)                    |
| 3D          | three.js + React Three Fiber + drei                             |
| Анимация    | motion (Framer Motion) + Lenis (плавный скролл)                 |
| Типографика | Unbounded (дисплей) · Manrope (текст) · IBM Plex Mono (лейблы)  |

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # продакшн-сборка
npm run start   # запуск собранного сайта
```

## Структура

```
app/
  page.tsx            Главная: 3D-герой → интро → цифры → калькулятор в ноутбуке →
                      продукция → инсайт → процесс → вопросы → CTA
  platforma/          Калькулятор тиража во всю ширину + описание платформы
  produkciya/         Каталог направлений с интерактивной 3D-витриной
  proizvodstvo/       Производственная база, этапы, контроль цвета
  kultura/            Ценности, инсайт, команда
  kontakty/           Форма заявки и реквизиты
components/
  layout/             Шапка, подвал, плавный скролл
  sections/           Экраны страниц (переиспользуются между страницами)
  calculator/         Калькулятор и макет ноутбука
  three/              Сцены: герой, объекты продукции, общее окружение
  ui/                 Примитивы: пилюли, кнопки, появление блоков
content/site.ts       ← ВЕСЬ ТЕКСТ САЙТА
lib/pricing.ts        ← ЛОГИКА И ТАРИФЫ КАЛЬКУЛЯТОРА
```

## Как подставить финальный контент

1. **Тексты.** Всё содержимое собрано в `content/site.ts`. Вёрстку менять не нужно —
   правится только этот файл. Места с предварительной редактурой помечены
   комментарием `// TODO(pdf)`.
2. **Тарифы калькулятора.** Коэффициенты (цена бумаги за м², стоимость форм, приладки,
   отделки, переплёта, логистики) живут в `lib/pricing.ts` — заменяются на
   производственный справочник. Формулы расчёта цены и срока трогать не требуется.
3. **Контакты и реквизиты.** Блок `contacts` в `content/site.ts`.

## Что ещё не подключено

- **Приём заявок.** Форма на `/kontakty` работает только на клиенте: обработчик
  `submitLead` в `components/sections/ContactForm.tsx` — заглушка, ожидающая
  запроса в CRM или почтовый шлюз.
- **Отправка сметы в работу.** Кнопка в калькуляторе ведёт на страницу контактов;
  передача конфигурации в заявку добавляется тем же обработчиком.

## Доступность и производительность

- 3D грузится только на клиенте (`components/three/Lazy.tsx`), первый экран отдаётся
  статикой.
- Окружение сцен собрано из источников света внутри three — внешние HDRI не грузятся.
- `prefers-reduced-motion` отключает плавный скролл, появления и раскрытие ноутбука.
- Видимый фокус на всех интерактивных элементах, вёрстка адаптируется до 390 px.
