# Культура девелопмента — сайт

Реализация макета `Сайт - Культура девелопмента v2.dc.html` из хендофф-бандла Claude Design
на Next.js (App Router) + TypeScript.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
```

## Структура

```
src/
  app/
    layout.tsx          Manrope через next/font, подключение токенов
    page.tsx            порядок секций страницы
    icon.svg            favicon
  components/
    ds/                 компоненты дизайн-системы, перенесённые из _ds_bundle.js
      Logo.tsx          логотип «культура девелопмента» (+ logoPaths.ts — контуры SVG)
      BarChart.tsx      гистограмма с подсказкой на стекле
      Input.tsx         стеклянное поле (+ glassDefs.ts — SVG-фильтры liquid glass)
    sections/           по компоненту на секцию макета + CSS-модуль
      BrainCore.tsx     canvas-ядро «мозг» (частицы по силуэту, разлёт при наведении)
  data/calculator.ts    сценарии, ТЭП, затраты, чувствительность, выводы по вкладкам
  styles/
    globals.css         база страницы
    tokens/             токены дизайн-системы (цвета, типографика, стекло, движение)
public/assets/          рендеры и фото из бандла
```

Исходный бандл остаётся в репозитории: `project/` — макеты и дизайн-система,
`chats/` — расшифровки обсуждения с заказчиком, `README.md` — описание хендоффа.

## Что стоит знать

**Токены дизайн-системы** скопированы из бандла без изменений, кроме одного:
`tokens/glass.css` ссылался на `assets/liquid-glass.svg`, которого в экспорте нет.
Переменные `--glass-refract*` теперь указывают на фильтры, которые `ds/Input.tsx`
внедряет в документ (`#kd-glass`, `#kd-glass-soft`, `#kd-glass-deep`).

**Keyframes живут внутри CSS-модулей**, а не в `globals.css`: css-modules локализует
и определение `@keyframes`, и ссылку на него в `animation`. Если вынести определение
в глобальный файл, имена перестают совпадать и анимация молча не работает.

**Заглушки, ожидающие подключения:**

- форма «Запросить демо» валидируется браузером и показывает подтверждение,
  но никуда не отправляется — эндпоинт не подключён (`sections/LeadForm.tsx`);
- блок карты в контактах — плейсхолдер под Яндекс.Карты (`sections/Contacts.tsx`).

## Адаптив

Прототип рассчитан на 1440 px и почти не содержит медиазапросов. Раскладка доведена
до рабочего состояния на диапазоне **320–1280 px**; на десктопе она не изменилась.

- **Шапка.** До 980 px пункты меню уезжают в бургер — открывается панель со всеми
  разделами и кнопкой «Запросить демо». Меню закрывается по клику на пункт, по фону
  и по Escape, скролл страницы под ним заблокирован. До 560 px кнопка в пилюле
  прячется (она есть в меню), до 380 px логотип уменьшается.
- **Сетки.** `repeat(auto-fit, minmax(320px, 1fr))` распирает контейнер, когда трек шире
  вьюпорта. Везде заменено на `minmax(min(320px, 100%), 1fr)` — 14 мест.
- **Точечно:** кегль героя и «Жизненного цикла» на узких экранах, перенос внутри слова
  в длинных заголовках, `min-width` заголовка калькулятора, KPI-строки внутри ноутбука,
  зона нажатия у ссылок футера.
- **График «Рост прибыли»** скроллится внутри карточки: пять подписей не сжимаются
  ниже своей ширины и иначе распирали бы блок.

Проверено скриптом на 320 / 360 / 390 / 414 / 480 / 640 / 768 / 1024 / 1280 px:
горизонтального скролла нет ни на одной ширине, элементы не выходят за пределы вьюпорта.

**Движение.** Все анимации выключаются при `prefers-reduced-motion: reduce`;
`BrainCore` дополнительно останавливает вращение и покачивание.
